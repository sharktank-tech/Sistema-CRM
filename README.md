# Sistema CRM

## Sistema de CRM para centralizar dados de contatos, histórico de compras e interações

### Funcionalidades:
- *Gestão de contatos*: Cadastro unificado de histórico de iterações
- *Funil de vendas*: Visualização das etapas de negociação, desde a prospeção até o prós-venda
- *Automação de Processos*: Disparo de e-mails, agendamento de tarefas e lembretes automáticos para a equipe comercial.
- *Relatórios e métricas*: Dados e gráficos para tomada de decisões estratégicas.
